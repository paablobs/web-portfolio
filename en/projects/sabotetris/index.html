Sabotetris

Tetris-style game with escalating chaos effects and local/global rankings. React, Excalibur.js and a Supabase/PostgreSQL backend with Edge Functions.

  • React
  • TypeScript
  • Excalibur.js
  • Supabase
  • PostgreSQL
  • Edge Functions
Source codeLive app

Problem & scope

Build a Tetris-style browser game with timed chaos effects, softcore and hardcore modes, and local rankings that can work independently of the online leaderboard.

Implementation & architecture

A React interface surrounds the Excalibur.js/TypeScript game engine. Chaos effects are selected from a pool unlocked by the current level.

Global rankings use Supabase anonymous authentication, Edge Functions to create and submit runs, and PostgreSQL for storage and ranking queries. Local history stays separate from online submissions.

Decisions & tradeoffs

Prepare an online run before gameplay instead of uploading arbitrary local history afterward. Validate submissions server-side and use request limits and idempotency to reduce abuse and duplicate submissions.

Keep local play available when online services are disabled or fail. Rankings are separated by mode so different rulesets are not mixed.

Testing & verification

Node regression tests exercise ranking limits, storage failures, disabled-online behavior, guest CAPTCHA handling and offline fallback.

The repository also provides PostgreSQL tests, Edge Function type checking, lint and build commands. These are separate checks for the browser, service boundary and database.

Current limitations

Scores are calculated by the client. Server validation and rate limits reduce abuse but do not make the leaderboard an authoritative or cheat-proof competitive system.

Online publishing requires connectivity and a run prepared before the game. Existing local scores are not uploaded retroactively. This is not an opponent-to-opponent multiplayer game.
