Web Portfolio

Bilingual portfolio rendered to static HTML with Astro and React. Localized routes, project case studies, metadata and automated navigation/build checks.

  • Astro
  • React
  • TypeScript
  • SCSS Modules
  • Vitest
  • GitHub Actions
Source codeLive app

Problem & scope

Present professional experience and engineering projects in English and Spanish, with content that is available immediately and navigable without JavaScript.

Implementation & architecture

Astro owns document metadata, localized routes and build output. React sections render at build time without hydrated islands; SCSS Modules share design tokens.

A project catalog supplies cards, localized case-study routes and sitemap entries. A small browser script enhances the mobile menu, language links and scroll controls.

Decisions & tradeoffs

Static rendering keeps the content independent of client-side React startup. The existing root URL remains available and points canonically to the English version.

Language selection links to the equivalent localized page. Existing project URLs remain available even when they are no longer featured on the homepage.

Testing & verification

Vitest tests cover menu behavior, Escape handling, scroll thresholds, reduced motion and language-link fragments.

Generated-HTML checks inspect localized content, canonical and alternate URLs, images, internal links, CV download, case studies, sitemap entries and the absence of hydrated React islands.

Current limitations

Content updates require a rebuild. There is no CMS or contact-form backend; contact is through email and professional profile links.

Project descriptions and test configurations are documented in the source repositories. This site does not provide live test-run reports or usage analytics.
