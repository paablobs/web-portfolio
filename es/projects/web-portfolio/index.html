Web Portfolio

Portfolio bilingüe generado como HTML estático con Astro y React. Rutas localizadas, casos de estudio, metadatos y comprobaciones automatizadas de navegación y build.

  • Astro
  • React
  • TypeScript
  • SCSS Modules

  • GitHub Actions

Problema y alcance

Presentar experiencia profesional y proyectos técnicos en español e inglés, con contenido disponible de inmediato y navegable sin JavaScript.

Implementación y arquitectura

Astro gestiona metadatos, rutas localizadas y generación del sitio. Las secciones React se renderizan durante el build sin islas hidratadas; los SCSS Modules comparten tokens de diseño.

Un catálogo de proyectos alimenta tarjetas, rutas de casos de estudio y sitemap. Un pequeño script mejora el menú móvil, los enlaces de idioma y los controles de desplazamiento.

Decisiones y compromisos

El renderizado estático evita depender del arranque de React en el navegador para leer el contenido. La URL raíz existente se conserva y declara la versión inglesa como canónica.

El selector de idioma enlaza a la página localizada equivalente. Las URLs de proyectos existentes siguen disponibles aunque dejen de destacarse en el inicio.

Pruebas y verificación

Vitest comprueba el menú, Escape, umbrales de desplazamiento, movimiento reducido y fragmentos en enlaces de idioma.

Las comprobaciones del HTML generado revisan contenido localizado, URLs canónicas y alternativas, imágenes, enlaces internos, ausencia de archivos públicos del CV y enlaces de descarga, casos de estudio, sitemap y ausencia de islas React hidratadas.

Limitaciones actuales

Actualizar contenido requiere recompilar. No hay CMS ni backend de formulario; el contacto se realiza por email y perfiles profesionales.

Las descripciones y configuraciones de pruebas están documentadas en los repositorios. El sitio no ofrece reportes de ejecución de pruebas ni analítica de uso en vivo.
