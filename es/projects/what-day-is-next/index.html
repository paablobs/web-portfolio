What Day Is Next?

Una pequeña aplicación React que calcula el próximo día de la semana, con un tono divertido y una interfaz oscura enfocada en una sola interacción.

  • React
  • TypeScript
  • Chakra UI
  • Vite
Código fuenteVer aplicación

Problema y alcance

Ofrecer una pequeña interfaz lúdica para calcular el próximo día de la semana.

Implementación y arquitectura

React y TypeScript resuelven la interfaz, con componentes Chakra UI y build Vite.

Decisiones y compromisos

Mantener una interacción acotada y fácil de entender. Este proyecto pequeño de UI se conserva como ejemplo adicional, no como la principal evidencia de ingeniería full stack.

Pruebas y verificación

El repositorio permite revisar la interfaz y el cálculo de días. Este caso de estudio no afirma contar con cobertura automatizada de pruebas.

Limitaciones actuales

Aplicación deliberadamente pequeña y exclusivamente frontend: no demuestra servicios backend, persistencia ni comportamiento de sistemas distribuidos.
