# Web Portfolio

Bilingual (English and Spanish) portfolio for Pablo Bessone, a full stack developer with a frontend focus and professional experience in React, TypeScript, Node.js/NestJS, APIs and ERP integrations.

The homepage separates professional experience from technologies explored in personal projects. Each featured project also has a case study that documents implementation, tradeoffs, testing and limitations.

It is a static site built with Astro, React, TypeScript and SCSS Modules, and it works without JavaScript.
